# Western Baltic herring catalogue component (subdivisions 22–24)

## Identity and current assessment

The metadata-only record `ck_ices_hawg_harengus_wbs_22_24` describes the
historical subdivisions 22–24 component. The current official ICES assessment
is the 2026 assessment of spring-spawning herring in subdivisions 20–24
(`her.27.20-24`). It uses one SAM population model for the broader area. The
canonical database already contains that production run as
`ices_herring_western_baltic`, including its source inputs and outputs.

The 22–24 catalogue component is therefore not a separate current assessment
unit. Its historical observations or estimates cannot be treated as an
independent 2026 fit, and the populated 20–24 data must not be copied into a
second set of records for this component.

## Database decision

Keep the catalogue row metadata-only. Do not add a duplicate assessment event,
inputs, outputs, tinyAM fit, or dashboard. Reconsider only if an official
assessment again reports a distinct 22–24 production model with recoverable
source data.
