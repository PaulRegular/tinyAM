# North Sea sandeel catalogue identity

Charbonneau–Keith `ICES-HAWG_dubius_NS` names *Ammodytes dubius*, labels its
area North Sea and cites the full HAWG 2016 report. That report covers separate
regional sandeel assessments. It does not identify one current assessment
area for this catalogue row. The checked 2026 Northeast Atlantic analysis
subset contains no corresponding sandeel series that would establish a
numerical match; absence from that subset does not establish absence from
every historical catalogue analysis.

Current ICES production assessments use *Ammodytes* spp. and distinguish
areas 1r, 2r and 3r, with Area 4's latest recoverable age-based assessment
separate from its newer data-limited advice. Boundaries and assessment status
have changed since 2016. Neither the catalogue's species label nor the broad
North Sea area establishes a one-to-one link to any one regional run.

The legacy stock ID and Charbonneau identifier are preserved. Regional
records have their own verified stock codes, without invented catalogue IDs.
[Area 1r](ices_sandeel_area_1r.md), [Area 2r](ices_sandeel_area_2r.md) and
[Area 3r](ices_sandeel_area_3r.md), and the detailed [Area 4](ices_sandeel_area_4.md)
run now have verified regional records. This does not silently resolve the
legacy taxonomy or establish an age-based model for the other data-limited units.

The official 2026 regional repositories were found under `ices-advice`, not
the older `ices-taf` organization. Their `DATA.bib` files refer to local folders
absent from the pinned public trees. The public smsR example represents an
older run and cannot replace the selected 2026 data. Current report tables
and source code remain the verified numerical/methodological fallback.

The original catalogue PDF, raw metadata/data snapshot, repository metadata
and inspection logs are cached in `source_cache/ck_ices_hawg_dubius_ns/`.
Actual assessment data and provenance are stored separately for each region.
