# Alaska plaice: female catalogue entry

## Assessment relationship

The Charbonneau–Keith female entry is a sex-specific label for the Bering
Sea/Aleutian Islands Alaska plaice management stock. The current detailed run
is the final 2024 Model 24.1b, recorded as `afsc_alaska_plaice_bsai_2024`. The
assessment fits one stock with both sexes and retains sex-specific inputs and
outputs.

## Database decision

The official run is represented under `afsc_alaska_plaice_bsai`, with sex
stored as a data dimension. This catalogue row has no distinct assessment
event; duplicating the female data here would misstate the model as a separate
stock fit. Associate any tinyAM comparison with the canonical stock.
