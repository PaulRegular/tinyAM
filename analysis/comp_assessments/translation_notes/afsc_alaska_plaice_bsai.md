## Expanded-library review

### tinyAM translation and numerical result

The translation uses 2000–2023 and ages 5–25+. Biomass and joint-sex age
proportions are converted to numbers using sex-specific computed mid-year
weights before pooling sexes or restricting ages. Only three fishery age
samples are available; length samples are omitted. Stock biology uses an
equal-sex approximation, holding source growth estimates fixed. M remains
0.13. Survey observations are divided by the source's **fixed** calibration
exp(0.182322), with a logistic q curve constrained to asymptote 1; no fitted
q or fitted population state is used to adjust observations. Source
sex-specific selectivity, ageing error, length likelihood and composition
weights are not reproduced. Initial ages are free, F follows independent
random walks, and age-5 recruitment has an estimated constant mean and SD.

The current package-default run failed both allowed initialization attempts.
The default attempt returned optimizer code 1, objective 433.152, maximum
gradient 0.182 and a non-positive-definite Hessian. The single aligned
source-start retry returned code 1, objective 354.758, maximum gradient
52,503,477 and a non-positive-definite Hessian. Fixed-effect covariance was
unavailable for both attempts. An SD-report object alone does not establish a
valid fit.

The cached dashboard and comparison values below were generated by an older
run and do not match the current initialization diagnostics. They are retained
only as historical artifacts and must not be interpreted as validated
agreement: that run reported modeled-age SSB MAPD 3.73%, terminal difference
−13.38%, correlation 0.981; N-at-age 29.71%, +10.23%, 0.816; total abundance
45.22%, +77.25%, 0.277; age-5 recruitment 110.75%, +18.18%, 0.698; and
N-weighted F-at-age 587.46%, +1201.45%, −0.177. The current comparison exports
do not contain rows for this assessment because neither current fit passed
checks. Fixed M is checked only for input consistency. Native age-0 recruitment
and all-age SSB remain separate; no combined uncertainty is invented.

An alternative with an age-logistic mean and AR1 temporal F process was tested
with package defaults followed by the permitted aligned source-start retry.
The retry still failed numerical checks (optimizer code 1, gradient 4,441 and
non-positive-definite Hessian). Its point comparisons are not interpretable
because the fit failed; no alternative F process is retained. Current results
therefore support no validated agreement claim for this translation. The
source structure remains the closest guide for a future attempt, but the
present model and its initialization need further work before reporting
fit-derived comparisons.

## Paper-working-set review before migration

Only distinct notes from the earlier main review are retained below. Their settings and diagnostics may differ from the expanded-library recipe.

### tinyAM translation and numerical result

Default initialization failed (code 1, false convergence; maximum gradient
about 203000; non-positive-definite Hessian). The one permitted retry from
aligned pooled N and N-weighted F converged: code 0, objective 296.489,
maximum gradient 0.000904, positive-definite Hessian and successful SD report.
Both attempts are saved; data and model settings were unchanged.

The local dashboard compares native outputs and explicitly labelled common
definitions. Modeled-age female SSB is approximate because tinyAM pools sexes:
MAPD 3.73%, terminal difference −13.38%, correlation 0.981. This does not mean
the other states agree. N-at-age is 29.71%, +10.23%, 0.816; total abundance
45.22%, +77.25%, 0.277; age-5 recruitment 110.75%, +18.18%, 0.698; and
N-weighted F-at-age 587.46%, +1201.45%, −0.177. Very small juvenile F makes
relative differences especially large. These metrics require review. Fixed
M is checked only for input consistency. Native age-0 recruitment and all-age
SSB are retained separately; no combined uncertainty is invented.
