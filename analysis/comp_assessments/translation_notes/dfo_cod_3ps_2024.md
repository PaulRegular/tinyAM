# DFO 3Ps Atlantic cod, 2024 assessment: tinyAM translation notes

Transferred from the pre-cleanup SAIO review without refitting. Check the registered stock script and review tier for current settings. [Official source review](https://github.com/PaulRegular/saio/blob/main/source_reviews/dfo_cod_3ps_2024.md).

## tinyAM translation readiness

The translation recipe is in [preliminary recipe](../scripts/translation/preliminary/dfo_cod_3ps_2024.R). It uses reported catch-at-age directly, fits the five index series with independent age-by-survey q values, approximates seasonal timing by within-season midpoints, uses an age-correlated F random walk without the source age-2 separation or 1993 break, and models log M with age-specific levels and separate condition slopes for ages 2–5 and 6+. The N process is now IID to represent independent cohort-survival deviations, with exponential initial abundance. These remain approximations: tinyAM does not reproduce censored zero-index observations, censored landings intervals, continuation-ratio catch composition, the exact condition-to-M relationship, or all HYBRID process structures. Survey index units remain unresolved, with survey-specific q absorbing the reported scale.

The updated recipe first used package-default initialization. Numerical checks failed: `nlminb` returned code 1 (`singular convergence (7)`), with a maximum gradient of 0.000753. The Hessian was positive definite and `sdreport` returned, but the fixed-parameter covariance contained non-finite values. After that failure, one documented retry used the published age-2 recruitment and Fbar estimates for 2020-2024 as starting values only; recruitment was converted from million fish to tinyAM's thousand-fish scale and Fbar initialized ages 5-8 equally. All other parameters retained package defaults, and observations and model settings were unchanged. The retry returned optimizer code 0 (`relative convergence (4)`) and a lower objective of 2100.817, with a maximum gradient of 0.000606, but the fixed-parameter covariance still contained non-finite values. It therefore also failed numerical checks. Both attempts had 80 fixed effects and 1,703 random effects, a positive-definite Hessian, and an advisory that the F-increment age correlation was near its boundary. No converged-fit dashboard was produced; treat both fits and their uncertainty as unavailable. The recipe test verifies the year and age grid, timing, IID N setting, two condition-effect columns, comparison window, and alignment/scale of available source starts. Its observation converter is stubbed, so it does not validate source-to-observation conversion or establish a successful fit.

A one-off sensitivity replaced the age-correlated F process with independent temporal random walks while keeping the IID N process, recruitment, M condition effects, data, and likelihood settings unchanged. It also returned singular convergence (code 1); the maximum gradient was 0.000381 and the Hessian was positive definite, but fixed-parameter covariance remained unavailable. Removing the estimated F-age correlation therefore did not resolve the numerical failure. No converged-fit dashboard is available.

Two additional initial-state sensitivities used the same data, likelihood and process settings without supplied starts. `init = "latent"` failed (optimizer code 1, objective 2077.477, maximum gradient 2.84, and non-positive-definite Hessian). `init = "free"` reached optimizer code 0 (objective 2056.290, gradient 0.001215, positive-definite Hessian), but its fixed-parameter covariance remained non-finite, so it also failed the package convergence checks. Neither version supports a reliable comparison or dashboard; the original recipe is unchanged.
