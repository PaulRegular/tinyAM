**Latest advice located:** 2023 assessment, advice for 2023–2024
**Screening result:** ineligible for the age-disaggregated assessment set

The 2026 HAWG report lists the Category 5.3 analysis for Area 7r as last
updated in 2019. It describes the 2023–2024 advice method as ICES Category 5,

does not establish a newer age-structured assessment. No newer area-specific

ineligible for the current age-disaggregated set. No canonical assessment or
