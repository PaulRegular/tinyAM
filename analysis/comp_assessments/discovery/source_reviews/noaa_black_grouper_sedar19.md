# South Atlantic and Gulf of Mexico black grouper (NOAA:14148)

**Reviewed:** 2026-11-02
**Inventory record:** NOAA Stock SMART 14148
**Assessment unit:** South Atlantic and Gulf of Mexico black grouper (*Mycteroperca bonaci*)
**Screen:** Screened; age-disaggregated input eligibility remains unresolved. No canonical assessment records were added.

## Identity and latest assessment

Stock SMART identifies assessment 5223 (2010; data through 2008; SEFSC) as Full acceptance, using ASAP version 2.0.19. SEDAR 19 treats the Gulf of Mexico and South Atlantic population as one assessment unit. No matching *Mycteroperca bonaci* stock is present in the canonical database.

The SAFMC's 2026 management-procedure review says SEDAR 19 was the only formal black grouper assessment and that the 2017 Stock Synthesis effort was suspended because catch records were too uncertain. It also notes that data were revised in 2017. Those revisions are not a completed production assessment and are not substituted for SEDAR 19.

## Inputs and outputs located

- **Population model and years:** The final SEDAR 19 report describes an ASAP2 statistical catch-at-age model with four fleets over 1986–2008. The model uses ages 1–20+, with the oldest ages grouped.
- **Catch-at-age and age compositions:** The assessment uses age-composition data and states that commercial catch-at-age is handled within the model. The report provides age-sample counts and relative age-composition figures, but the reviewed files do not expose the complete fleet-by-year catch-at-age inputs or the numerical composition likelihood data. Longline age samples are absent for the first selectivity block (1986–1991). This is a key unresolved source gap.
- **Abundance indices:** The report summary describes five indices, including an FWC visual-survey age-1 index. Its post-review configuration note says the selected base run excluded the RVC and FWC visual indices, while the 2026 overview describes eight indices for the 2010 assessment. The exact index set for the final accepted run therefore needs confirmation from final-run files or tables; no native ASAP data file was located.
- **Biology and mortality:** The report includes age-specific life-history summaries, including M and female/male maturity, and documents growth and age adjustments. It also identifies a correction to longline discard weight-at-age in the final configuration (Table A2.1.2). The assessment concerns a protogynous species, so sex-specific biological assumptions matter.
- **Survey timing:** The assessment is annual. A within-year timing fraction for the final index set was not verified.
- **Official outputs:** The final report provides annual beginning-of-year abundance and stock biomass at age for 1986–2008, ages 1–20+ (Table A3.3.4.9), plus fishing-mortality-at-age and aggregate spawning biomass and recruitment results. These are useful official age-specific outputs.

## Screen decision

**Eligibility remains unresolved, rather than ineligible.** The official assessment clearly uses age-structured data and reports age-specific population outputs. However, the numerical fleet-by-year catch-at-age and composition inputs, final accepted index configuration, and timing details have not been verified from public source files during this screen. The 2026 review also records substantial uncertainty in catch records and confirms that the 2017 assessment effort did not produce a replacement official fit.

Keep this stock in the discovery register as a screened, promising source-recovery candidate. Do not create canonical input or output records from figures or fitted states.
