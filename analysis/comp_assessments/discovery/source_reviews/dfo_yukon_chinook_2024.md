# Yukon Chinook SMU (assessment in 2024)

The DFO Pacific inventory row `DFO:Pacific:Chinook Salmon - Yukon` refers to Yukon River Chinook salmon (*Oncorhynchus tshawytscha*). The latest official assessment located is the 2024 assessment, summarized in DFO Science Advisory Report 2026/008. The report distinguishes the Yukon Chinook SMU from the Porcupine Chinook SMU; together they are the proposed Yukon River Chinook major stock. The age-specific run reconstruction and spawner-recruitment assessment described in the detailed report cover the nine CUs of the Yukon Chinook SMU only. Porcupine is data deficient for those analyses. No matching Yukon unit is in the canonical database. The unrelated NOAA “Eastern North Pacific Far North Migrating” stock is a much broader US-managed reporting unit, and no one-to-one crosswalk is supported by the sources reviewed.

The detailed Research Document is still labelled in press in the public assessment repository. Its PDF is pinned to the repository's 4 November 2025 revision, while the current repository snapshot retrieved 2026-10-30 is 21 commits newer and has changes to model code and several source/generated data files. The repository says its contents are subject to change. The current repository outputs therefore establish that detailed material is publicly accessible, but they are not treated here as a frozen production-run release or as values verified against the pinned PDF. DFO's 2026/008 summary independently confirms that the run-reconstruction assessment derives escapement, harvest and returns by age, and reports aggregate catch, spawner abundance, exploitation-rate and return summaries.

## Evidence for age-disaggregated inputs and outputs

| Component | Evidence and limitation |
|---|---|
| Catch at age | The public repository contains fishery, district and stock catch counts with salmon age categories (`Age1.1` through `Age2.5`) for 1981–2024. These are numbers of fish, but their run/SMU alignment and use in the final production likelihood have not been verified. The detailed spawner-recruitment model instead describes externally derived aggregate catch, spawner abundance and age-composition inputs. |
| Abundance index and age data | Daily border passage counts from sonar and fish wheels span 1985–2024, and an aggregate mark-recapture border-passage index is supplied for earlier years. The run-reconstruction code models daily arrival over Julian days 160–285, with CU composition samples. Separate annual sex-specific age compositions cover ages 4–7. These sources support age-structured reconstruction, but do not provide a directly observed age-specific annual survey-index matrix. |
| Weights and maturity | Age, sex and length samples are reported and available. The detailed analysis uses age-at-return probabilities for ages 4–7 and converts female size, age and sex composition to total egg mass using a fecundity/egg-mass relationship. A conventional weight-at-age and maturity-at-age input surface for the current assessment was not verified. Egg mass is not interchangeable with stock biomass. |
| Mortality | The assessment does not estimate a conventional annual F-at-age or M-at-age surface. In the CU run reconstruction, post-border spawners are estimated assuming no en-route adult migration mortality; catch and exploitation are handled at aggregate levels, with common historical exploitation assumed across CUs where needed. This is not a complete age-specific mortality specification for a tinyAM cohort model. |
| Timing | The primary abundance observations are in-river daily counts and a mark-recapture index. The run-reconstruction code uses Julian days 160–285 and models run timing directly; this is not a standard annual trawl-survey timing fraction. |
| Outputs | The official summary states that the run reconstruction derives escapement, harvest and returns by age; it also reports aggregate catch, spawner abundance, exploitation and returns, with age/sex/length trends. The detailed analysis has CU-level spawner-recruitment outputs and derived returns by age, but complete, run-matched numeric N/F/M-at-age tables for the final production assessment were not verified. |

## Screening decision

Record this as a distinct new Yukon Chinook SMU candidate, not as the whole Yukon–Porcupine major stock and not as the older Yukon mainstem-only unit in DFO Research Document 2022/031. Screening is complete and the candidate remains **eligibility unresolved**: the public materials contain substantial age-resolved source information and an age-structured spawner-recruitment analysis, but the exact production-run catch and age matrices, conventional weight/maturity surfaces, mortality assumptions, and final numeric age-specific outputs are not aligned and verified together. This is a documented source-evidence limitation, not a claim that the assessment lacks age data. Do not import values or select this unit for the translation batch until the final detailed run and its files can be reconciled.
