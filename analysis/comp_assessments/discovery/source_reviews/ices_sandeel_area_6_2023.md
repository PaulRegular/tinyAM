# ICES sandeel Area 6

**Stock code:** `san.sa.6` (Ammodytes spp.), Kattegat
**Latest advice located:** 2023 assessment, advice for 2023–2024
**Screening result:** ineligible for the age-disaggregated assessment set

The 2026 HAWG report lists the Category 5.2 analysis for Area 6 as last
updated in 2019. It describes the 2023–2024 advice method as ICES Category 5,
which uses catch data only. The 2023 Advice and Scenarios Database record
allows up to 140 tonnes of catch in each of 2023 and 2024; its associated stock
graph gives a 2022 catch entry of 42 tonnes. These sources provide no
catch-at-age, survey-at-age, weight-at-age, maturity-at-age, age-specific M,
or comparable age-specific population outputs.

Area 6 remains in the ICES stock inventory, but inventory membership alone
does not establish a newer age-structured assessment. No newer area-specific
advice record or age-based production run was located in the sources reviewed.
Catch advice is not a comparable population-state estimate, so this unit is
ineligible for the current age-disaggregated set. No canonical assessment or
numerical data were added.
