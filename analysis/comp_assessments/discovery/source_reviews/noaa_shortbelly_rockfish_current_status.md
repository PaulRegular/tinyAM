# Shortbelly rockfish (NOAA:10398): current assessment screen

## Current unit and status

The NOAA inventory snapshot lists Shortbelly rockfish, *Sebastes jordani*, with a 2007 assessment year. The archived 2007 NOAA technical memorandum describes a population model for the California Current, developed from the 2006 assessment cycle.

The current Pacific Coast Groundfish Fishery Management Plan, amended through 2026, does not list Shortbelly rockfish among managed groundfish stocks. It lists the species as an ecosystem component (EC) species. The plan records that Amendment 29 designated it as an EC species in 2020. This means the 2007 model is historical context, not the current production assessment for an active assessed stock unit.

## Screening decision

Screen NOAA:10398 as ineligible for the current-assessment inventory. Do not use the 2007 model as a substitute for a current production assessment, and do not add canonical inputs, outputs, or an assessment event. This is a scope exclusion, not a finding that the archived model lacks age-structured data.
