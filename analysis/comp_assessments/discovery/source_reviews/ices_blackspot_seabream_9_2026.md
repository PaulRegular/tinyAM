# Blackspot seabream in ICES Subarea 9 (`sbr.27.9`)

Review date: 2026-10-30

## Unit and latest advice

The current ICES stock unit is blackspot seabream (*Pagellus bogaraveo*) in
Subarea 9, Atlantic Iberian waters. The latest advice record located is
assessment year 2026, stock category 3, for 2027–2028. Its advice is no more
than 28 tonnes in each year.

## Latest advice-linked data

The 2026 Standard Graphs page labels stock size as SSB in tonnes, but the SSB
chart panel is empty. Its source-data table contains annual landings only for
2003–2025; it provides no tabulated SSB values or age-specific inputs or
population outputs for the 2026 advice record.

## Detailed earlier assessment located

The 2025 ICES WKBSS3 benchmark report accepted a Stock Synthesis (SS3) model
for this stock. The stock-specific chapter describes a model with input data
through 2023, and the accompanying working document identifies its model
output as a 2024 WKBSS3 SS3 run. It reports aggregate recruitment, SSB, and F
trajectories with uncertainty.

This earlier SS3 model does not supply observed age-disaggregated inputs. The
report explicitly states that no age data were available for the Portuguese
and northern Spanish coasts and that the model used length compositions from
2009–2023, commercial landings, and a standardized Portuguese polyvalent-fleet
CPUE index. Its base case set empirical weight-at-age unavailable, borrowed
length-weight and maturity relationships from the Strait of Gibraltar GFCM
model, and used an age-specific M curve derived from that model. The model's
age structure is therefore inferred from length data and borrowed biological
assumptions, rather than supported by the age-disaggregated observations
required for the current tinyAM comparison scope.

The benchmark is useful detailed documentation, but it is not identified as
the run underlying the later 2026 advice. The current 2026 advice-linked
source table contains landings only. The 2025 model outputs are retained as
evidence that aggregate outputs exist; they are not recorded as outputs of
the 2026 assessment.

## Screening decision

This is a distinct new ICES unit, screened **ineligible** for the
age-disaggregated comparison set. The latest advice-linked source lacks
age-specific inputs, and the detailed earlier SS3 assessment explicitly says
that age data are unavailable and fits length compositions instead. The
benchmark's aggregate model outputs do not change that input limitation.
This decision does not assert that unreviewed age samples do not exist
elsewhere.

No canonical stock, assessment, input, or output records were added. No
tinyAM translation was attempted.
