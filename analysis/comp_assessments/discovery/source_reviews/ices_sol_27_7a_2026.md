# Irish Sea sole: 2026 discovery review

ICES `sol.27.7a` is *Solea solea* in the Irish Sea. The canonical sole records describe other areas; none identifies division 7.a. The [2026 WGCSE report](https://doi.org/10.17895/ices.pub.32625759), section 19, presents a SAM assessment with 1970-2025 data and ages 1-10+. The exact relationship of this working-group run to the final 2026 advice still needs confirmation.

The report provides catch numbers-at-age in thousands (Table 19.2), catch and stock weights-at-age in kg (Tables 19.3 and 19.5), and tuning series (Table 19.9). Its model uses the UK(E&W)-BTS-Q3 survey at ages 1-7, 1988-2025, excluding the missing 2020 survey; its specified survey interval is 0.75-0.85 of a year. A Belgian commercial biomass index is also used. Catch age 1 before 2003 is set missing for model fitting even though the printed catch table contains entries. The report prints a fixed age-specific mortality vector for ages 1-10+ and describes a revised, time-varying survey-derived maturity ogive. Tables 19.13-19.16 report fitted F and N at age, SSB-at-age and annual summaries. Verify each table's units, missingness and interval definitions against the production run during curation.

The [pinned ICES code repository](https://github.com/ices-advice/2026_sol.27.7a/tree/bff4518e75378685700c849a24c5ba9c86e5a575/2026_sol.27.7a_assessment) describes its `mo.txt` maturity input, but the archive contains code and bibliography rather than the local numerical input files or fitted object. The report shows maturity in figures, not an identified numeric matrix. Recover the revised production maturity data and confirm the selected run before classifying eligibility; do not infer maturity from fitted output or substitute an older ogive.
