# North Sea witch: 2026 discovery review

ICES `wit.27.3a47d`, *Glyptocephalus cynoglossus* in Subarea 4 and divisions 3.a and 7.d, is a distinct Northeast Atlantic assessment unit from the Northwest Atlantic witch records in the canonical database. [ICES 2026 advice](https://asd.ices.dk/viewAdvice/5104) identifies assessment key 22534.

Section 23 of the [2026 WGNSSK report](https://doi.org/10.17895/ices.pub.32676345.v2) describes SAM input catch-at-age for 2009-2025 at ages 1-10+, with aggregate landings for 1950-2008. Table 23.4 prints the catch-at-age values but does not state a multiplier in its caption; verify the scale using original model inputs before conversion. Tables 23.5a-c and 23.6 report catch, landings, discard and fixed stock weight-at-age, and Table 23.7 gives the fixed maturity ogive. Natural mortality is 0.2 per year at all ages. Table 23.8 and the [official assessment graph source data](https://standardgraphs.ices.dk/ViewSourceData.aspx?key=22534) give historical summaries; Tables 23.9 and 23.10 provide estimated F and N at age.

The model uses age-specific Q1 IBTS and combined Q3 IBTS/BTS survey biomass indices from 2009-2025. The report describes these series and plots them but does not identify complete numeric age-index matrices in the reviewed tables. Older survey observations are aggregate biomass indices and should not be treated as age-specific. Exact within-year timing and the numerical survey series must be recovered and checked before classifying eligibility.

The pinned [2026 ICES assessment code](https://github.com/ices-advice/2026_wit.27.3a47d/tree/030bc61156d1369af85e77afd8f7c17d1d50ca0a/2026_wit.27.3a47d_assessment) explicitly identifies `wit.27.3a47d_2026` on stockassessment.org as the source of data and configuration, matching the working-group report. The reviewed public assessment archive contains the workflow code but not the numerical input files from that data directory or a fitted object. The working-group tables establish age ranges and summarize catch, survey, biology and outputs, but the complete numerical age-specific survey series and timing were not recovered, and the catch-table multiplier remains unconfirmed. Screening is complete; eligibility remains unresolved until these run-matched source inputs and scales are verified. Do not substitute an older run. The code additionally fills some historical values for its own model setup, so distinguish these from original observed data.

The official WGNSSK witch section, code archive and SAG source page are cached in `source_cache/discovery_ices_witch_northsea_2026/`; `sources.csv` records URLs, retrieval date and SHA-256 checksums. The repository revision is `030bc61156d1369af85e77afd8f7c17d1d50ca0a`. This discovery review does not create a canonical record.
