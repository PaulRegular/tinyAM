# West Coast Vancouver Island Barkley Sockeye (2024 assessment)

DFO's Pacific inventory row identifies the West Coast Vancouver Island Barkley Sockeye Stock Management Unit (SMU), *Oncorhynchus nerka*. The 2024 assessment covers the Great Central, Sproat, and Hucuktlis Conservation Units (CUs), which remain components of one assessment unit rather than separate candidate stocks.

The 2026 Science Response says that the latest full assessment was in 2012 and the latest interim update was 2024. It describes the 2024 assessment as using multiple approaches: index-based abundance, stock-recruit relationships, forecasts, and annual run reconstruction. The report says age and stock composition for the three CUs are reconstructed to evaluate catch, exploitation, recruitment, and demographic trends. Data include fishway counts, spawning-ground surveys, fence counts, fishery catch monitoring, lake acoustic/trawl fry surveys, and smolt age samples.

This is not evidence of the conventional age-structured population model inputs sought for this inventory. The reviewed 2024 response does not provide a complete catch-numbers-at-age likelihood, an age-specific marine abundance index, age-specific weight and maturity vectors, natural-mortality assumptions, or annual N-at-age/F-at-age population surfaces. It reports aggregate/component harvest, escapement, exploitation rate, recruits per spawner, and biological reference points. The row is therefore screened ineligible for the age-disaggregated assessment set, despite age composition being used in salmon run reconstruction. No canonical assessment data were added and no tinyAM translation was attempted.
