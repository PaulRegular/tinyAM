## 2026 working-group tables

The [2026 WGBIE report, section 7](https://doi.org/10.17895/ices.pub.32790321.v1), supplies numerical input and output tables for this assessment. Tables 7.4-7.6 report catch numbers, catch weights and stock weights at ages 2-8+ for 1984-2025; Table 7.2 gives the fixed maturity ogive. Table 7.7 gives French BTS VIII standardized age-specific indices for ages 2-7 in 2007-2025; Table 7.8 gives the trawler biomass index in 2010-2025. The report describes the BTS series as the index used by the 2026 assessment. Table 7.11 reports annual SSB and recruitment with intervals labeled 90%, while Tables 7.14-7.15 give annual F and N at age.

Two source issues prevent verification of the exact 2026 production inputs. Table 7.4 labels catch as numbers-at-age but does not state the numerical multiplier. Multiplying the rounded catch numbers by catch weights produces totals close to, but not equal to, the reported catches; this is a plausibility check, not a source-backed scale confirmation. Table 7.3 prints M at ages 2–8+ as 0.13, 0.12, 0.11, 0.10, 0.10, 0.10, 0.09, whereas the model settings in section 7.4.2 print 0.13, 0.12, 0.11, 0.11, 0.10, 0.09, 0.09. The 2024 benchmark corroborates the settings vector, but does not establish which vector entered the 2026 run. The settings table also says the final data year is 2026, while its accompanying text and input tables end in 2025. These contradictions were confirmed visually in the report.

The official sole section is cached as `wgbie_2026_sole_north.pdf` under this candidate's source cache. The public bootstrap bibliography and report do not establish the exact 2026 catch multiplier or production-run M vector, so eligibility remains unresolved.
## Benchmark and earlier-source cross-check

The [2024 flatfish benchmark](https://doi.org/10.17895/ices.pub.25471987.v1), Table 4.1 and section 4.6, gives the same mortality vector as the 2026 settings table: 0.13, 0.12, 0.11, 0.11, 0.10, 0.09, 0.09. The 2026 report says its model configuration follows the 2024 benchmark. This corroborates that vector but does not prove which vector was supplied to the 2026 run. The [2025 WGBIE report](https://doi.org/10.17895/ices.pub.29390639.v4) contains the same discrepancy between its settings and Table 7.3. Keep both 2026 report statements traceable and seek the actual run input.

The 2021 stock annex predates the 2024 benchmark and states constant M=0.1; it cannot resolve the current run's age-specific M. As a scale check, multiplying the rounded 2026 report catch numbers and catch weights gives 4,151.6 for 1984 and 2,826.5 for 2025; the reported total catches are 4,107 and 2,737 tonnes, respectively. A thousand-fish scale is plausible, but the discrepancies and the absence of an explicit table multiplier prevent treating it as verified.
