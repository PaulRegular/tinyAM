# ICES southern black-bellied anglerfish (`ank.27.8c9a`)

Reviewed 2026-10-30. ICES's latest stock register identifies the current unit as black-bellied anglerfish in divisions 8.c and 9.a. The 2026 Category 1 production assessment (Standard Graphs key 23769) supports advice for 2027.

WGBIE's 2026 report classifies the current assessment as a surplus-production model. The model is not an age-structured assessment: catch-at-age, age-specific survey indices, weights-at-age, and maturity-at-age are not model inputs. The generic Standard Graphs page includes an “Age and Length” heading, but its F-age field is blank, consistent with the report's model description.

Standard Graphs reports recruitment (age 0), SSB in tonnes, catches, and aggregate F with 90% intervals. It does not report historical N-at-age, F-at-age, or M-at-age surfaces. The series may be useful for an aggregate comparison, but this unit is ineligible for the age-disaggregated input set.
