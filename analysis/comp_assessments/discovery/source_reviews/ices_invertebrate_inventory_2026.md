# ICES invertebrate inventory identity reconciliation

The 2026 ICES Stock Information Database snapshot lists 32 Norway lobster
(*Nephrops norvegicus*) and northern shrimp (*Pandalus borealis*) inventory
entries. Their official ICES stock codes and scientific names were checked
against the pinned snapshot (`source_cache/discovery_ices_sid/stock_list_2026.json`,
retrieved 2026-10-28; SHA-256
`913D6A3EEAB9449AE3CD0DD15661A150D36FF79B6E6A9BA78D86D46BA1035F42`). Each
code is retained as a distinct candidate unit because the SID presents it as a
separate stock key. No corresponding canonical stock or numerical assessment
records exist in the database.

These crustaceans are outside the initial marine-finfish discovery scope, so
they remain screened ineligible. This is a scope decision only: the assessment
methods, age data, model inputs, outputs, and source completeness have not been
audited. No assessment event or numerical data were added to the canonical
database.
