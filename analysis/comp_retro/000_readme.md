
The goal of this analysis was to evaluate retrospective patterns across several
formulations of a relatively simple Northern cod assessment model, relative to the
extended Northern cod assessment model (xteNCAM). At the time, xteNCAM was exhibiting
substantial retrospective patterns, and one question was whether those patterns were
being driven by assumptions about the underlying population processes.

Across the simpler tinyAM formulations examined here, retrospective patterns were
generally small. It was later determined that the larger retrospective patterns in
xteNCAM were driven primarily by conflicts between the tagging data and other model
inputs: as the fishery increased, the number of tag returns was lower than expected.
Tag data are not used in these tinyAM models.

In the end, this analysis served as the first real-world test of tinyAM.
It provided an opportunity to evaluate alternative population-process assumptions,
retrospective diagnostics, projections, and overall package functionality using a
well-studied stock assessment problem.
